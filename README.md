# 📊 Linear Regression Learning System

An interactive web-based application that helps users understand and visualize Linear Regression step-by-step using their own dataset.

---

## 🚀 Live Demo

🔗 https://mouly19.github.io/Linear-Regression/

---

## 📌 Features

* 📁 Upload CSV dataset
* 📊 Data visualization (graphs & plots)
* 📉 Linear Regression model implementation
* 📈 Evaluation metrics (MSE, MAE, RMSE, R² Score)
* 🔍 Predicted vs Actual comparison
* 📉 Residual analysis
* 🎯 Step-by-step learning approach (no black-box)

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Chart.js

---

## 🎯 Objective

To build an educational tool that explains Linear Regression with clear visualizations and intuitive interaction for students.
