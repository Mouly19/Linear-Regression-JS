📖 Hypothesis Formulation

Linear regression assumes the target variable y is a linear combination of input features x plus Gaussian noise. The model learns the weights (parameters) that best fit the observed data.

Simple Linear Regression

One input feature x predicts a continuous output y. The model is a straight line:

Hypothesis Function ŷ = β₀ + β₁ · x where: β₀ = intercept (bias term) — value of ŷ when x = 0 β₁ = slope (weight) — change in ŷ per unit increase in x

Multiple Linear Regression

n input features x₁, x₂, …, xₙ:

Hypothesis Function (vectorized) ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ ŷ = β₀ + Σᵢ βᵢxᵢ ŷ = βᵀx (adding x₀=1 to absorb β₀)

📖 Cost Function — What Are We Minimizing?

The cost function J(β) measures how "wrong" our predictions are on average. We use Mean Squared Error (MSE). Squaring penalises large errors more harshly and produces a smooth, differentiable surface convenient for optimisation.

Mean Squared Error — Cost Function J(β₀, β₁) = (1/2m) · Σᵢ₌₁ᵐ ( ŷᵢ - yᵢ )² = (1/2m) · Σᵢ ( β₀ + β₁xᵢ - yᵢ )² where m = number of training examples, (1/2) simplifies the gradient

The goal of training is to find β₀ and β₁ that minimise J(β₀, β₁). The cost surface is a convex paraboloid — it has exactly one global minimum, which makes optimisation well-behaved.

Residual for a single sample i eᵢ = ŷᵢ - yᵢ = (β₀ + β₁xᵢ) - yᵢ J = (1/2m) · Σ eᵢ²

📖 Gradient Descent — Iterative Optimisation

Gradient Descent iteratively adjusts parameters by moving in the direction of steepest descent on the cost surface. The learning rate α controls step size. Too large → overshoots; too small → slow convergence.

Partial Derivatives of J ∂J/∂β₀ = (1/m) · Σᵢ ( ŷᵢ - yᵢ ) ∂J/∂β₁ = (1/m) · Σᵢ ( ŷᵢ - yᵢ ) · xᵢ
Simultaneous Parameter Update Rule β₀ := β₀ - α · ∂J/∂β₀ β₁ := β₁ - α · ∂J/∂β₁ Repeat until convergence (|ΔJ| < ε or max epochs reached)
Vectorized Form (Multiple LR) β := β - (α/m) · Xᵀ(Xβ - y)

📖 Normal Equation — Analytical (Closed-Form) Solution

For linear regression, we can solve for the optimal parameters analytically by setting the gradient to zero. This avoids iterative optimisation but requires matrix inversion (O(n³) — expensive for large feature sets).

Simple Linear Regression — Closed Form β₁ = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)² β₀ = ȳ - β₁ · x̄ where x̄, ȳ are the feature and target means
Multiple LR — Normal Equation (Matrix Form) β = (XᵀX)⁻¹ · Xᵀ · y X is the (m × n+1) design matrix with a column of 1s prepended This gives the exact optimal solution in one step
